# บรีฟลงสนาม — สำหรับไปออกแบบต่อในระบบอื่น

รวมทุกอย่างที่ตกลงกันไว้เป็นบรีฟที่ยืนอยู่ได้ด้วยตัวเอง คัดลอกไปวางในระบบไหนก็ได้
โดยที่ระบบนั้นไม่ต้องรู้จักโปรเจกต์นี้มาก่อน

แต่ละบรีฟมี **ข้อห้ามที่เคยพลาดมาแล้ว** กำกับไว้ เพื่อไม่ให้เสียเวลาไปกับทางที่ปฏิเสธไปแล้ว

```text
ช่วยออกแบบต่อยอด design system สำหรับเว็บแอปชื่อ "ลงสนาม" (Longsanam)

## โปรดักต์คืออะไร
แอปรวมก๊วนกีฬาสมัครเล่นในไทย ผู้จัดตั้งก๊วน ส่งลิงก์เข้ากลุ่ม LINE เพื่อนกดเข้าร่วมและจ่ายเงิน
พอครบยอดระบบจองสนามให้อัตโนมัติ ถ้าจองไม่ได้คืนเงินเต็ม
กีฬาที่รองรับ: แบดมินตัน ฟุตบอล เทนนิส บาสเกตบอล พิคเคิลบอล
ผู้ใช้เกือบทั้งหมดเปิดลิงก์จากแชท LINE บนมือถือ กลางแดด

## กติกาที่ห้ามละเมิด (มาจากการวัด WCAG ไม่ใช่รสนิยม)
1. ตัวอักษรขาวบน brand-500 = 3.19:1 ตก AA
   → อะไรก็ตามที่เขียนบนเขียวสว่าง ใช้หมึก #0d1f18 (5.37:1)
   → ถ้าจำเป็นต้องใช้ตัวอักษรขาว ให้เปลี่ยนพื้นเป็น brand-600 (5.37:1)
2. accent-500 บนขาว = 1.38:1 → เป็นสีพื้น แถบวัดผล ไฮไลต์ เท่านั้น ห้ามเป็นตัวอักษรทุกกรณี
3. ink-400 ต้องผ่าน 3:1 บนขาว เพราะแบกไอคอนในการ์ด
4. ธีมเดียว สว่างอย่างเดียว โดยตั้งใจ ไม่ต้องออกแบบโหมดมืด
5. พื้นเป็นขาว และการ์ดก็ขาว → การ์ดต้องมีเส้นขอบ hairline เสมอ ไม่งั้นหายไปกับพื้น
   ใช้แถบสีเขียวจาง #f1f9f4 คั่นบทแทนการพึ่งเงา
6. ตัวเลขคือเนื้อหา — เงินและจำนวนคนใช้ tabular-nums เสมอ เลขเปลี่ยนค่าต้องไม่ดันเลย์เอาต์
7. ภาษาไทยต้องการ line-height 1.7 ขึ้นไป และ letter-spacing ต้องเป็น 0 สำหรับ :lang(th)
   เพราะมันดันสระและวรรณยุกต์ออกจากตำแหน่ง หัวข้อภาษาลาตินเท่านั้นที่ opt in ได้
8. โมชันขยับได้แค่ transform กับ opacity ห้ามแอนิเมต layout สี หรือเงา
   และต้องเคารพ prefers-reduced-motion แบบตัดทิ้ง ไม่ใช่ลดความเร็ว

## สิ่งที่อยากได้เพิ่ม
- คอมโพเนนต์ที่ยังขาด: bottom sheet, date/time picker แบบไทย, empty state,
  skeleton, toast, ตารางสรุปยอดเงิน, การ์ดใบเสร็จ
- ระบบระยะห่างและ type scale ที่เขียนเป็นตัวเลขได้ ไม่ใช่บรรยาย
- แนวทางสำหรับหน้าจอที่มีตัวเลขเงินเยอะ ๆ โดยไม่ให้ดูเป็นสเปรดชีต

## สิ่งที่ห้ามเสนอ
- โหมดมืด
- เปลี่ยนคู่ฟอนต์
- เพิ่มสีที่สี่ (มีแค่ เขียว ไลม์ ดินเผา)
- ไล่เฉด (gradient) บนคอมโพเนนต์ ระบบนี้เป็นภาพแบน
- glassmorphism, neumorphism, หรือเอฟเฟกต์กระจกฝ้า

## รูปแบบผลลัพธ์ที่ต้องการ
1. ตาราง token พร้อมค่า hex และคำอธิบายว่าแต่ละตัวใช้ตรงไหน
2. อัตราส่วนคอนทราสต์ของทุกคู่สีที่จะเอาไปใช้จริง คำนวณมาให้ อย่าประมาณ
3. สเปกคอมโพเนนต์เป็นตัวเลข (padding, radius, ความหนาเส้น, ขนาดฟอนต์)
4. ถ้าเสนอสิ่งที่ขัดกับกติกา 8 ข้อข้างบน ให้บอกตรง ๆ ว่าขัดข้อไหนและทำไมถึงคุ้มที่จะขัด
```

## บรีฟ 2 — Mascot "น้องสนาม"

ตัวเดิมสร้างจากหุ่นข้อต่อ ทุกท่าคือชุดมุมหมุนของหุ่นตัวเดียว ไม่ได้วาดมือทีละท่า
ถ้าปลายทางทำแบบเดียวกันได้ จะได้ท่าใหม่ในอนาคตฟรี

```text
ช่วยออกแบบมาสคอตชื่อ "น้องสนาม" สำหรับแอปรวมก๊วนกีฬาไทยชื่อ "ลงสนาม"

## บุคลิกที่ต้องการ
คนธรรมดาที่ชอบเล่นกีฬา ไม่ใช่นักกีฬาอาชีพ เป็นกันเอง สนุก ทันสมัย
เป้าหมายคือทำให้หน้าจอที่ยังว่าง ๆ ไม่น่ากลัว เช่นหน้าที่ยังไม่มีก๊วน หรือหน้ารอคนครบ

## ต้องมีท่าครบ 5 กีฬา + 1 ท่าตั้งต้น
แบดมินตัน · ฟุตบอล · เทนนิส · บาสเกตบอล · พิคเคิลบอล · ท่ายืนตั้งต้น
(ทั้งห้ากีฬานี้คือกีฬาที่มีอยู่จริงในฐานข้อมูลของแอป ห้ามเพิ่มกีฬาที่แอปไม่รองรับ)

## วิธีสร้างที่อยากให้ใช้ — สำคัญกว่าตัวรูป
ขอให้สร้างจาก "หุ่นข้อต่อ" ตัวเดียว แล้วทุกท่าคือการหมุนข้อ ไม่ใช่วาดใหม่ทีละท่า
ข้อต่อ: ไหล่ ศอก สะโพก เข่า ข้อเท้า
ความยาวกระดูกคงที่ทุกท่า (สัดส่วนที่ใช้อยู่: แขนบน 34, ปลายแขน 30, ต้นขา 38, หน้าแข้ง 34,
รัศมีหัว 26, ไหล่ห่างแกนกลาง ±26, สะโพก ±10)
ผลลัพธ์คือแขนขาเท่ากันทุกรูปโดยไม่ต้องคอยเทียบ และท่าใหม่ในอนาคตคือชุดตัวเลข ไม่ใช่งานวาด

## กติกาการวาด
- สีเสื้อเขียว #12a563 · กางเกงหมึก #0d1f18 · รองเท้าไลม์ #bfec33
- ผ้าคาดหัวสีไลม์ คือสิ่งที่ทำให้จำตัวละครได้แม้ย่อจนไม่เหลือหน้า — ห้ามตัดออก
- หน้ามีแค่ตาสองจุดกับปากหนึ่งเส้น ไม่มีคิ้ว ไม่มีจมูก ย่อเหลือ 24px ต้องยังอ่านออก
- ภาพแบน ไม่มีไล่เฉด ไม่มีเงาตกกระทบบนตัว
- เส้นขอบมีได้เฉพาะอุปกรณ์กีฬา เพื่อให้ของที่ถือแยกออกจากมือ
- เท้าต้องราบกับพื้นเสมอ ยกเว้นท่าเตะและท่ากระโดด
- มีเงาใต้เท้าเสมอ เงาหดเล็กลงเมื่อตัวลอย
- ขีดสั้น ๆ สีไลม์สองสามเส้นใช้บอกทิศทางแรง แทนเส้นสปีดแบบการ์ตูน

## ข้อห้าม
- ห้ามเพิ่มสีที่สี่ ถ้าอุปกรณ์กีฬาต้องมีสี ให้หยิบจากดินเผา #c2643b หรือไลม์ที่มีอยู่
- ห้ามเปลี่ยนสัดส่วน หัวโตกว่านี้จะเป็นเด็ก เล็กกว่านี้จะเป็นนักกีฬาอาชีพ
- ห้ามใส่ปากอ้า ตาโต หรือแววตาประกาย น้องสนามยิ้มแบบเดียว
- ห้ามใช้ประกอบข่าวร้าย — จอยกเลิกก๊วนหรือจ่ายเงินไม่ผ่าน ห้ามมีมาสคอต
  มาสคอตมีหน้าที่ทำให้หน้าจอว่างไม่น่ากลัว ไม่ใช่ทำให้ข่าวร้ายดูน่ารักขึ้น
- ห้ามวางบนพื้นเขียวเข้ม เสื้อจะกลืนกับพื้น

## รูปแบบผลลัพธ์ที่ต้องการ
- ไฟล์ SVG แยกท่าละไฟล์ ใช้ viewBox เดียวกันทุกท่า
- ถ้าเป็นไปได้ ขอสูตร/พารามิเตอร์ของแต่ละท่า (มุมของแต่ละข้อ) มาด้วย ไม่ใช่แค่ path ที่วาดเสร็จแล้ว
- ขนาดที่ต้องใช้จริง: 144px (หน้าว่าง), 72px (หัวการ์ด), 40px (อวตาร)
  ถ้าที่ 40px ตัวเต็มอ่านไม่ออก ให้เสนอแบบย่อที่เหลือเฉพาะหัวกับผ้าคาด
```

## บรีฟ 3 — Logo

อันนี้ผ่านมาสี่รอบแล้ว บรีฟจึงบอกทั้งสิ่งที่อยากได้ และสิ่งที่ลองแล้วไม่เอา พร้อมเหตุผล

```text
ช่วยออกแบบโลโก้ให้แอปรวมก๊วนกีฬาไทยชื่อ "ลงสนาม" (Longsanam)

## แนวที่ต้องการ
รูปคนวิ่ง/เคลื่อนไหว ที่ประกอบจากเส้นหนาปลายมนไม่กี่เส้น ความหนาเส้นเท่ากันทั้งตรา
สไตล์แบบ pictogram สมัยใหม่ — เส้นไหลลื่น ให้ความรู้สึกพุ่งไปข้างหน้า
หัวเป็นวงกลมแยกออกมาจากลำตัว ไม่ต่อกัน
สองสีเท่านั้น ไม่มีไล่เฉด ไม่มีเส้นขอบ ไม่มีเงา

## โจทย์พิเศษ — การอ่านซ้อน
อยากให้รูปคนวิ่งนั้น เมื่อมองอีกมุมหนึ่ง อ่านเป็นตัวอักษรไทย "ล" ได้ด้วย
(ล คือพยัญชนะตัวแรกของชื่อแบรนด์ "ลงสนาม")

โครงหลักของ ล ที่ต้องเห็น: หัว (ห่วงกลม) อยู่ล่างซ้าย → เส้นขึ้นเป็นส่วนโค้งด้านบน → เส้นลงทางขวา
แนวทางที่เคยลองแล้วเวิร์ก: ให้ห่วงที่ปลายเท้าหลังของคนวิ่ง ทำหน้าที่เป็นหัวของ ล
และให้ขาที่ก้าวออกไปเป็นเส้นลงขวาของตัวอักษร

**สำคัญ: รูปคนวิ่งต้องเป็นการอ่านหลัก การอ่านเป็น ล เป็นการอ่านซ้อน**
เคยพลาดมาแล้วเพราะทำ ล ให้ชัดจนไม่เหลือคนวิ่ง

ข้อดีที่เข้าทาง: คำว่า "ลง" แปลว่าพุ่งลงไป/ก้าวลงไป ท่าคนโน้มตัวไปข้างหน้าจึงเป็นความหมายของชื่อพอดี

## สี
เขียว #0a7a4f หรือ #076140 กับไลม์ #bfec33
ข้อบังคับ: ไลม์บนเขียว #12a563 วัดได้ 2.32:1 อ่านไม่ออก
ถ้าจะวางไลม์บนพื้นเขียว ต้องเป็น #076140 หรือเข้มกว่า (5.46:1)
บนพื้นขาว ให้ตราเป็นเขียว #0a7a4f (5.37:1)

## ต้องใช้ได้ในสถานการณ์เหล่านี้
- หัวเว็บขนาดสูง 26px และหน้า sign-in สูง 30px (ปัจจุบันใช้จริงเท่านี้)
- ไอคอนแอป iOS (มุมโค้ง), Android (วงกลม), ปุ่มริชเมนู LINE (สี่เหลี่ยม)
- favicon 16px
- แบบสีเดียวสำหรับตรายางและงานพิมพ์สีเดียว
- คู่กับตัวอักษร "ลงสนาม" ในฟอนต์ Bai Jamjuree 700 ทั้งแนวนอนและแนวตั้ง
```

## รอบกลับ — ส่งกลับมาแบบไหนถึงใช้ต่อได้เลย

ส่วนนี้ไม่ต้องคัดลอกไปไหน เป็นบันทึกไว้สำหรับตอนรับของกลับมา

1. **SVG ดีกว่า PNG เสมอ** — ถ้าได้ SVG แปลงเป็นคอมโพเนนต์ React ที่ใช้ theme token ได้ตรง ๆ
   สีจะผูกกับระบบ ไม่ใช่ hex ตายตัว ถ้าได้มาเป็น PNG ต้องวาดใหม่ตามอยู่ดี
2. **ถ้าเป็น stroke path จะดีที่สุด** — โลโก้ที่ยังเป็นเส้น (ไม่ใช่ outline ที่แปลงแล้ว)
   ปรับความหนาได้ทีหลังโดยไม่ต้องวาดใหม่ ซึ่งสำคัญตอนย่อลง 16px
3. **ขอค่า hex ทุกตัวที่ใช้** — จะได้เช็คคอนทราสต์ก่อนเอาลงโค้ด
   ที่ผ่านมาเจอสองครั้งที่สีสวยแต่ตกเกณฑ์
4. **มาสคอต ขอมุมข้อต่อด้วยถ้ามี** — ถ้าได้แค่รูปก็ใช้ได้ แต่ถ้าได้พารามิเตอร์
   จะทำเป็นสคริปต์สร้างท่าใหม่ได้เอง ไม่ต้องกลับไปหาคนวาดทุกครั้ง
5. **วางไฟล์ไว้ที่ไหนก็บอก** — หรือแปะ SVG มาในแชทตรง ๆ ก็อ่านได้

### สิ่งที่จะทำต่อเมื่อได้ของกลับมา

- แปลงเป็นคอมโพเนนต์ที่ผูกกับ token
- คำนวณคอนทราสต์ทุกคู่แล้วใส่ `assert` กันไม่ให้ค่าที่ตกเกณฑ์หลุดเข้าโค้ด
- ทำหน้าคู่มือแบรนด์ที่สร้างจากสคริปต์เดียวกับที่แอปใช้ เพื่อไม่ให้คู่มือกับของจริงเพี้ยนจากกัน
