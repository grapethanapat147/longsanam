# Longsanam — Direction 04 / Human in Motion

เริ่มดูที่ **design-review.html** หรือ **logo-options.png**

## ทิศทางตามข้อความและ ref ล่าสุด

รอบนี้ผ่อนข้อกำหนดเดิมที่ทำให้คาแรกเตอร์แข็ง: ไม่บังคับความยาวกระดูก ไม่บังคับหน้าเพียงจุด/เส้น และไม่ฝืนซ่อนตัว ล ในโลโก้

คงชื่อแบรนด์ ฟอนต์ Bai Jamjuree + Anuphan และสี UI เดิม ใช้ ref เพื่อศึกษามวลหนา เส้นโค้งไหล ปลายตัด และหัววงกลมแยก โดยวาดโครง SVG ใหม่

## Logo

- **A / Flow Runner — ตัวเลือกแนะนำ:** เห็นคนวิ่งชัด จังหวะโค้งเชื่อมร่างกายและท่าก้าว
- **B / Play Wave:** ลดรูปให้เหมือนคลื่นและหนึ่งก้าว มีความ abstract มากกว่า
- **C / Forward Form:** มวลทึบ ปลายเฉียง และขาแยก ดูหนักแน่นกว่า

ทุกทางมี SVG สีเขียว สีเดียว และ reverse ใน `logo/`
A มี wordmark, favicon และตัวอย่าง app icon เพิ่มเติม
ไฟล์ A/B เป็น stroke path ที่ปรับความหนาได้ C เป็น filled paths เพื่อควบคุมมวลและปลายตัด
ดู viewBox 120 × 120; A stroke 18, B stroke 17 หน่วย; เว้นพื้นที่ว่างรอบตราอย่างน้อยเท่าเส้นผ่านศูนย์กลางหัว (22 หน่วย) ในงานใช้งานจริง
ยังไม่ใช่ผลทดสอบการจำตรากับผู้ใช้ และไม่ได้ส่งไฟล์ขึ้นแพลตฟอร์มใด

## Mascot

`mascot/human-play-sheet.png` เป็นงานภาพต้นแบบจาก **built-in imagegen** ผ่านการสร้างและปรับลดรายละเอียด 2 รอบ

- หนึ่งตัวละครผู้ใหญ่ ลักษณะเป็นมนุษย์มากขึ้น สัดส่วนและท่ามีการถ่ายน้ำหนัก
- แถวบน: ยืนทักทาย / แบดมินตัน / ฟุตบอล
- แถวล่าง: เทนนิส / บาสเกตบอล / พิคเคิลบอล
- ผม หน้ามีจมูก/คิ้ว รอยยิ้ม มือ และผ้าคาดเพิ่มการสื่ออารมณ์
- เสื้อเขียว กางเกงหมึก ผ้าคาดหัวไลม์คงเอกลักษณ์เดิม

**เป็น raster PNG ไม่ใช่ SVG แยกท่า ไม่ใช่หุ่นข้อต่อ และไม่ได้อ้างว่าทุกจุดใช้ค่า hex ตรง UI token**
การส่งต่อผลิตจริงควรวาด vector ตามภาพที่เลือกและตรวจ anatomy/อุปกรณ์อีกครั้ง ภาพนี้ใช้เป็นทิศทางภาพประกอบสำหรับรีวิวได้ทันที

Prompt ทั้งสองรอบอยู่ใน `source/image-prompts.md`

## Visual system

- ใช้โค้งสลับมุมตัด: card radius 24 / 6 / 24 / 6px; button 18 / 4 / 18 / 4px
- ปุ่มสูงอย่างน้อย 52px, padding 11 / 24px, line-height 1.7
- ฟอนต์และคู่สี UI คงตามระบบเดิม (tokens และ contrast แนบใน system/)
- สีผิว/สีครีมในภาพเป็น illustration-only ไม่เพิ่มเข้า semantic colors สำหรับ success/error
- `visual-language.css` คือ stylesheet ที่ใช้จริงในหน้ารีวิว รวม layout เพื่อการสาธิต
- ตัวอย่างปุ่มไม่มีการชำระเงินหรือเปลี่ยนสถานะภายนอก

## ตรวจแล้ว

- หน้า 320, 390, 768, 1440px ไม่พบ horizontal overflow
- ปุ่มตัวอย่างและ toast ทำงาน ไม่มี JavaScript page error ใน flow ที่ตรวจ
- prefers-reduced-motion ตัด transition เป็น 0s
- ตรวจภาพโลโก้ทั้งสามทางและ mascot sheet แล้ว
- SVG ทั้งหมด parse XML ผ่าน

## สร้างคู่มือและโลโก้ซ้ำ

ใช้ Python 3.9+ standard library:

```sh

```
