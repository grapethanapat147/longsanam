# ลงสนาม — Achievement Badges / SVG

วาดใหม่เป็น native SVG จากแนวคิด 6 แบบเดิม เพิ่มชื่อและคำอธิบายภาษาไทยใต้ plaque ตามคำขอล่าสุด ไม่ใช่ PNG ที่ฝังใน SVG

## ชื่อและความหมายที่เสนอ

| Badge | ระดับ | ข้อความใต้ภาพ |
|---|---|---|
| ทัวร์นาเมนต์แรก | Rare | ลงแข่งจนจบทัวร์นาเมนต์แรกของคุณ |
| คู่แข่งใหม่ | Common | จบแมตช์กับก๊วนที่ไม่เคยแข่งด้วยกัน |
| ขยับอีกขั้น | Rare | ลงแข่งครบ 5 ทัวร์นาเมนต์ |
| แชมป์ประจำรายการ | Elite | คว้าอันดับหนึ่งในทัวร์นาเมนต์ |
| น้ำใจนักกีฬา | Common | ได้รับคำชื่นชมเรื่องน้ำใจนักกีฬาหลังแข่ง |
| เพื่อนร่วมสนาม | Rare | แข่งกับก๊วนต่างกันครบ 3 ก๊วน |

ชื่อและเกณฑ์นี้เป็นข้อเสนอสำหรับการออกแบบ ยังไม่ได้เชื่อมกับ logic ของแอป จำนวน 5 ทัวร์นาเมนต์ / 3 ก๊วน และการให้ badge น้ำใจนักกีฬาจากคำชมอย่างน้อย 1 คนเป็นค่าเริ่มต้นที่ปรับได้ กติกาโดยละเอียดอยู่ใน badge-definitions.json

“ขยับอีกขั้น” นับการเข้าร่วมจนจบ ไม่ได้ยืนยันว่าฝีมือสูงขึ้น ส่วน “เพื่อนร่วมสนาม” นับก๊วนคู่แข่งที่เคยแข่งจริง ไม่ได้นับ friend request

## ไฟล์ใช้งาน

- badge-sheet-th.svg — ชีตรวม 3×2 พร้อมชื่อและคำอธิบายไทย ขนาด viewBox 1536×1260
- badge-sheet-th.png — ภาพ preview ของชีตข้อความ
- badge-sheet-icons.svg — ชีตรวมไอคอนล้วน ขนาด viewBox 1536×1080
- icons/ — SVG แยก 6 ไอคอน ไม่มีข้อความที่แสดงในภาพ viewBox 240×240
- labeled/ — SVG แยก 6 แบบมีชื่อและคำอธิบาย viewBox 480×610
- badge-48px-check.png — ภาพตรวจไอคอนแต่ละแบบที่ขนาด 48px
- fonts/ — Bai Jamjuree Bold และ Anuphan พร้อม license
- source/build.py — ต้นฉบับรูปทรงและข้อความ สร้าง SVG ด้วย Python standard library
- svg-checks.json — ตรวจสีและยืนยันว่าไม่มี embedded raster หรือ gradient
- layout-checks.json — ตำแหน่งข้อความจากการ render ใน Chrome

## สเปกภาพ

Plaque ขนาด 240×240: มุมซ้ายบนและขวาล่าง radius 48, มุมขวาบนและซ้ายล่างเป็นมุมฉาก Common มี border 6 หน่วย ขอบอยู่ภายในพื้นที่เดียวกับ Rare และ Elite ทุกแบบจึงมีขนาดภายนอกเท่ากัน

สีที่ใช้จริง: #0a7a4f, #12a563, #0d1f18, #bfec33, #ffffff เท่านั้น ไม่มี gradient, shadow, filter หรือ texture

Figure strokes และ court bars หนา 24; racket frame/shaft หนา 6; chevrons หนา 20; นิ้วมือหนา 14 ตามบทบาทของแต่ละองค์ประกอบ ปลาย stroke เป็น butt ทั้งหมด มุม join เป็น miter วงกลมและวงรีเป็น geometry จริง

มาสก์เชิงภาพหลัง chevrons ใช้เส้นสีพื้นเดียวกับ Elite เพื่อให้ไม้แบดอยู่ด้านหลังอย่างชัดเจน ไม่ใช่เงาหรือสีเพิ่ม หัวคนทุกแบบแยกจากตัว และแบบ social มี satellite dots 3 จุดเพิ่มเติมจากหัวคน

SVG กำหนดสีตรงตาม hex การดูหรือ export ผ่าน browser อาจมี anti-alias ที่ขอบจากตัว renderer ได้ ไม่ใช่สีหรือเอฟเฟกต์ที่ฝังใน SVG จึงไม่อ้างว่า PNG preview มีเพียง 5 ค่า RGB เท่านั้น

## ข้อความไทยและการนำเข้า

ชื่อและคำอธิบายยังเป็น SVG text ที่แก้ไขได้ พร้อม embedded fonts สำหรับ browser ไม่ได้แปลงตัวอักษรเป็น outline บางโปรแกรมออกแบบอาจไม่รองรับ embedded font ให้ติดตั้งฟอนต์ใน fonts/ ก่อนนำเข้า หากส่งโรงพิมพ์ ให้ตรวจฟอนต์แล้วแปลงข้อความเป็น outline ในโปรแกรมที่ใช้

สำหรับขนาด 48px ให้ใช้ไฟล์ icons/ แล้วให้แอปแสดงชื่อภายนอก ไม่ย่อทั้งชีตที่มีคำอธิบายลงเป็นไอคอน ความหมายรางวัลและเงื่อนไขควรปรากฏใน tooltip หรือหน้ารายละเอียดด้วย

ภาพชุดเก่าถูกเก็บไว้ ไม่ได้เขียนทับ ไฟล์ชุดใหม่นี้ใช้คำขอล่าสุดที่อนุญาตให้เพิ่มข้อความใต้ badge
