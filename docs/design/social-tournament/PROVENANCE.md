# ที่มาของชุดนี้

เกรพส่งมาเมื่อ 12 ก.ย. 2569 เป็น `longsanam-social-tournament.zip` (1.5 MB, 46 ไฟล์)
ผลิตในเครื่องมืออื่น และแจ้งว่า **ใช้ชุดนี้แทนต่อจากนี้**

ชุดนี้แทนที่ `docs/design/direction-04/` ในฐานะแหล่งอ้างอิงงานออกแบบ
ชุดเก่ายังเก็บไว้เพื่อให้ตามรอยได้ ไม่ได้ลบ

## ตรวจแล้วว่าอะไรเปลี่ยน อะไรไม่เปลี่ยน

### ไม่เปลี่ยนเลย — และนี่คือข้อที่ควรรู้ก่อนอื่น

| ตรวจอะไร | ผล |
| --- | --- |
| token สี ระยะ และมุมโค้ง | **เหมือนกันทั้ง 30 ตัว** กับที่ `src/app/globals.css` มีอยู่แล้ว |
| โลโก้แกนกลาง (`mark-primary.svg`) | **เหมือนกันทุกตัวอักษร** กับ `src/components/brand-mark.tsx` — สามเส้นเดิม `stroke-width 18` เดิม หัวที่ (72,21) r=11 เดิม viewBox 120×120 เดิม |
| ฟอนต์ที่ประกาศใน token | `--font-heading: Bai Jamjuree` · `--font-body: Anuphan` ซึ่ง `src/app/layout.tsx` โหลดผ่าน `next/font/google` อยู่แล้วทั้งคู่ |

**จึงไม่มีอะไรต้องแก้ใน `globals.css` และไม่มีอะไรต้องแก้ในโลโก้**
ชุดนี้คือชุดเดียวกับ direction 04 ที่แอปใช้อยู่ บวกของใหม่ด้านล่าง

  แอปใช้ Tailwind v4 แบบ CSS-first ไฟล์นี้เก็บไว้เป็นภาพอ้างอิงเท่านั้น

## ตรวจ contrast เองแล้ว ไม่ได้เชื่อไฟล์

คำนวณอัตราส่วนใหม่ทั้ง 17 คู่จากค่าสีตรง ๆ ด้วยสูตร WCAG relative luminance
**ตรงกับที่ไฟล์อ้างทุกคู่** (คลาดเคลื่อนน้อยกว่า 0.01) และ **ผ่านเกณฑ์ทุกคู่**
ไม่มีคู่ไหนที่ไฟล์อ้างว่าผ่านแล้วจริง ๆ ไม่ผ่าน

## ⚠️ กับดักในชุดนี้: `fonts/Anuphan.ttf` เป็น variable font

ไฟล์ฟอนต์ที่มาในชุด (231,712 bytes) มีตาราง `fvar` และ `gvar`

**ห้ามคัดลอกทับ `src/assets/fonts/`** ไฟล์นั้นคือไฟล์ที่ทำให้ `ImageResponse`
(Satori) โยน `Cannot read properties of undefined (reading '256')` แล้ว og:image
ของใบสรุปพังทั้ง route — เป็นบั๊กที่เพิ่งไล่หาเจอใน LSN-0023

แอปใช้ static instance ที่ตัดไว้แล้วคือ `Anuphan-Regular.ttf` กับ `Anuphan-Bold.ttf`
รายละเอียดและคำสั่งสร้างใหม่อยู่ใน `src/assets/fonts/README.md`

ส่วน `BaiJamjuree-*.ttf` ในชุดเป็น static ทั้งคู่ แต่แอปยังไม่ต้องใช้ไฟล์
เพราะหน้าเว็บโหลดผ่าน `next/font/google` และ og:image ยังไม่ใช้ฟอนต์หัวเรื่อง

## ข้อต่างเล็ก ๆ ที่ตั้งใจไม่แก้

`src/app/icon.svg` ที่ใช้อยู่ ต่างจาก `logo/app-circle.svg` ของชุดนี้แค่
`translate(22 21) scale(.64)` เทียบกับ `translate(23 22) scale(.62)`
มองไม่เห็นความต่างที่ขนาด favicon จึงไม่แก้

และ `logo/favicon.svg` ของชุดนี้เป็นมาร์คเปล่าไม่มีพื้นหลัง ซึ่งจะจางหายบนแท็บ
เบราว์เซอร์ธีมเข้ม ของที่แอปใช้อยู่เป็นมาร์คสีมะนาวบนวงกลมเขียวเข้ม ซึ่งเหมาะกว่า
สำหรับ favicon — **ไม่เปลี่ยนตาม**
