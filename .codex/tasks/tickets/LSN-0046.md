# 🟢 LSN-0046 — ทัวร์นาเมนต์มีตอนจบและมีแชมป์

**Type:** Feature · **Phase:** 11 · **Status:** Done
**Source:** ของที่ต้องปิดก่อน pilot ข้อ 1

## ปัญหา

`tournament_status` มีค่า `completed` ตั้งแต่ LSN-0029 แต่ **ไม่มีโค้ดตรงไหนตั้งค่านี้เลย**
(ตรวจแล้ว: ทั้ง repo ตั้ง `tournaments.status` แค่ `open` · `ready` · `cancelled`)

งานที่แข่งจบไปแล้วจึงค้างที่ `ready` ตลอดไป ผลคือ

* หน้าจอยังโชว์ "ประตูสามบาน" ของงานที่จบไปแล้ว พร้อมคำเตือน "ทีมครบขั้นต่ำ · ยังไม่ครบ"
  ที่ไม่มีใครทำอะไรกับมันได้
* **ไม่มีจุดไหนบอกว่าใครชนะ** ผู้จัดลงแรงจัดงานแล้วไม่เห็นว่าได้อะไรกลับมา
* ฝั่งก๊วนมี `complete_finished_sessions()` ทำงานนี้อยู่แล้วตั้งแต่ LSN-0001
  ฝั่งทัวร์นาเมนต์แค่ไม่เคยมีคู่ของมัน

## Scope

- `complete_finished_tournaments()` — ของเครื่อง เรียกจาก `runLifecycleSweeps()`
- `src/lib/domain/standings.ts` — ตารางคะแนนและแชมป์ คิดจากแมตช์ที่หน้าโหลดอยู่แล้ว
- หน้ารายละเอียด: แบนเนอร์ตอนจบ · การ์ดตารางคะแนน · ซ่อนประตูสามบานเมื่อจบ/ยกเลิก
- ฟอร์มบันทึกผลยังใช้ได้หลังงานจบ

## Decisions

### ปิดงานด้วยตัวจับเวลา ไม่ใช่ปุ่มของผู้จัด

ถ้าเป็นปุ่ม งานของผู้จัดที่ลืมกดก็ค้างเหมือนเดิม ซึ่งคือบั๊กที่ตั๋วนี้แก้อยู่พอดี
cron-job.org ยิง `/api/cron/expire` ทุกห้านาทีอยู่แล้ว ไม่ต้องตั้ง job ใหม่

### ตารางคะแนนไม่ใช้ RPC

หน้ารายละเอียดโหลดแมตช์ทั้งงานอยู่แล้วและ RLS กรองไว้ว่าใครเห็นงานไหน การเพิ่ม
RPC จะได้แค่ query เพิ่มหนึ่งครั้งกับผิวที่ต้องดูแลเพิ่มหนึ่งชิ้น ฟังก์ชันบริสุทธิ์
ยังเทสง่ายกว่าด้วย

### นับเฉพาะแมตช์ที่ยืนยันแล้ว

เหตุผลเดียวกับคะแนนฝีมือ (LSN-0031) — ผลที่ฝั่งเดียวพิมพ์เข้ามาเองยังไม่ใช่ผล
ถ้านับด้วย ก๊วนหนึ่งจะกรอกสกอร์ให้ตัวเองขึ้นหัวตารางได้ก่อนอีกฝั่งจะทันดู

### เสมอกันที่หัวตาราง = ยังไม่มีแชมป์

`championOf()` คืน `null` เมื่อสองอันดับแรกเท่ากันทุกเกณฑ์ การหยิบตัวแรกของ array
มาประกาศคือการให้รางวัลตามลำดับตัวอักษร ซึ่งแย่กว่าบอกตรง ๆ ว่ายังตัดสินไม่ได้

### ฟอร์มบันทึกผลต้องอยู่ต่อหลังงานจบ

`record_match` ยอมรับ `ready · booked · completed` อยู่แล้ว แต่หน้าจอเดิมโชว์ฟอร์ม
เฉพาะตอน `ready` ถ้าปล่อยไว้ การปิดงานอัตโนมัติที่ตั๋วนี้เพิ่งเพิ่มจะกลายเป็นตัว
ตัดไม่ให้ใครกรอกผลที่ค้างอยู่ — สร้างบั๊กใหม่จากการแก้บั๊กเก่า
