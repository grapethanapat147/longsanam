# LSN-0007 — Payment provider abstraction

**Type:** Feature · **Phase:** 2 · **Status:** Done

## Acceptance criteria
- [x] `PaymentProvider` interface: create, capture, cancel, refund, status.
- [x] `MockPaymentProvider` for local/demo, clearly labelled in the UI.
- [x] Provider resolved from `PAYMENT_PROVIDER` env with a safe default.
- [x] Idempotency key required on every mutating call.
- [x] Interfaces documented for a future Thai gateway (Omise/2C2P/PromptPay).

## Review notes
- The mock provider refused to refund charges it had not issued in the current
  process (seeded payments, or payments from a previous dev-server run). It now
  recognises its own `mock*` references, since the database — not an in-memory
  map — is the record of what was collected.
