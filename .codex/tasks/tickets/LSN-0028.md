# 🟢 LSN-0028 — Badge หลังจบทัวร์นาเมนต์

**Type:** Feature · **Phase:** 10 · **Status:** Backlog
**Spec:** `.codex/specs/badges.md`
**Artwork:** `docs/design/social-tournament/badges/` — เสร็จแล้วทั้งหกใบ
**Depends on:** **LSN-0027 → LSN-0026 → ตั๋วทัวร์นาเมนต์ (ยังไม่เปิด)** — ดู Blocking notes

## Goal

ผู้เล่นได้ badge ที่จับต้องได้หลังลงแข่งจบ เพื่อให้การลงแข่งครั้งนี้มีผลกับครั้งหน้า
และเป็นเหตุผลให้กลับมาลงอีก

## Context

artwork เสร็จแล้วทั้งหกใบ เป็น native vector อยู่ในพาเลตต์ token จริง
พร้อม `badge-definitions.json` ที่เสนอกติกาการให้ไว้แล้ว ตั๋วนี้คือส่วนที่เหลือ
คือฐานข้อมูล กติกา และหน้าจอ

## Scope

- ตาราง `player_badges` พร้อม `unique (user_id, badge_id)`
- ฟังก์ชัน `award_badges(p_user_id, p_tournament_id)` ที่ประเมินทุกใบและ idempotent
- catalog เป็นค่าคงที่ฝั่ง TS อ่านจาก `badge-definitions.json` ไม่มีตาราง catalog
- ตารางสะสมบนหน้าโปรไฟล์ ใบที่ยังไม่ได้แสดงเป็นเงาจาง
- badge ที่เพิ่งได้บนการ์ดหลังจบงาน
- ย้าย `badges/icons/` เข้า `public/` หรือ `src/assets/` ให้แอปเสิร์ฟได้

## Non-goals

- ไม่มี leaderboard เรียงจำนวน badge
- ไม่มี badge ที่ซื้อได้ หรือผู้จัดแจกเองตามใจ
- ไม่ ship `badges/labeled/` เข้าแอป — ใบละ 419KB เพราะฝังฟอนต์ รวม 2.4MB
- ไม่ทำ badge เฉพาะกิจรายอีเวนต์ในรอบแรก

## Acceptance Criteria

- [ ] เรียก `award_badges` ซ้ำกี่ครั้งก็ได้ badge ชุดเดิม ไม่เพิ่มแถว — ปักด้วยเทส
- [ ] `awarded_at` ไม่เปลี่ยนเมื่อเรียกซ้ำ (`do nothing` ไม่ใช่ `do update`) — ปักด้วยเทส
- [ ] badge ไม่สร้าง `credit_events` และไม่ขยับคะแนนฝีมือเลย — ปักด้วยเทส
- [ ] `05-fair-play` ไม่ให้เมื่อผู้ชื่นชมอยู่ก๊วนเดียวกันทั้งหมด — ปักด้วยเทส
- [ ] `05-fair-play` ไม่ให้เมื่อประเมินตนเอง — ปักด้วยเทส
- [ ] `03` และ `06` นับเฉพาะแมตช์ที่ยืนยันผลแล้ว ไม่นับการสมัคร — ปักด้วยเทส
- [ ] การให้ badge ทุกครั้งเขียน `app_log`
- [ ] ตารางสะสมใช้ไอคอนขนาด 64px ขึ้นไป ไม่ใช่ 48px
- [ ] ไม่มีปุ่มที่กดแล้วไม่ทำอะไร ใบที่ยังไม่ได้ต้องบอกเหตุผลว่าต้องทำอะไรถึงจะได้

## Validation

- `npm run lint`, `npx tsc --noEmit`, `npm test` ผ่าน
- `npm run test:db` ผ่าน รวมข้อใหม่ของตั๋วนี้
- migration apply จาก `npm run db:reset` ได้
- ตรวจด้วยเบราว์เซอร์: โปรไฟล์ที่ยังไม่มี badge เลย · มีบางใบ · ครบทุกใบ

## Blocking notes

**ตั๋วนี้เริ่มไม่ได้จนกว่าของสามอย่างจะมี** ตรวจกับฐานข้อมูลจริงแล้วยังไม่มีสักอย่าง

| ต้องมี | มาจากตั๋ว |
|---|---|
| ก๊วนที่คงอยู่ข้ามครั้ง | LSN-0026 (ซึ่งรอ LSN-0027 ก่อน) |
| `tournaments`, `teams` | ยังไม่เปิดตั๋ว |
| ผลแมตช์ที่ยืนยันจากสองฝั่ง | ยังไม่เปิดตั๋ว |

badge ทั้งหกใบอ้างถึง "ทัวร์นาเมนต์" หรือ "แมตช์ที่ยืนยันผล" จึงให้ใครไม่ได้
เลยสักใบในวันนี้ การเริ่มตั๋วนี้ก่อนจะได้ UI ที่โชว์ของที่ไม่มีวันได้
