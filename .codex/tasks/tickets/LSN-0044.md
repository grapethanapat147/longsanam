# 🟢 LSN-0044 — รุ่นมือกับช่องวันที่ที่คนทั่วไปอ่านออก

**Type:** Feature · **Phase:** 10 · **Status:** Done
**Source:** เกรพชี้สองตำแหน่งบนฟอร์มสร้างทัวร์นาเมนต์

## อาการ

1. ช่อง "รุ่นที่เปิดรับ" มีแค่ `N` `S` `P` `C` `B` `A` — คนที่เพิ่งเข้ามาไม่รู้ว่า
   อะไรสูงกว่าอะไร แต่ฟอร์มบังคับให้เลือกตั้งแต่ก่อนจะมีใครอธิบาย
2. แถว วัน / เดือน / ปี ช่องแรกโชว์ **"วั"** เพราะถูกบีบจนแคบกว่าคำว่า "วัน"
   ส่วนช่องเดือนกินพื้นที่ `1fr` ทั้งที่ไม่ต้องใช้ขนาดนั้น

## ต้นตอของข้อ 2

`Select` เติม `pr-8` เผื่อลูกศร **นอกเหนือจาก**ที่เบราว์เซอร์กันไว้ให้ลูกศรของ
ตัวเองอยู่แล้ว บนจอ 320px ช่องกว้าง 78px หักระยะขอบ 10+28 กับลูกศรอีกราว 16
เหลือที่ให้ข้อความ ~24px ขณะที่คำว่า "เดือน" กว้าง 28.9px (วัดด้วย canvas บนหน้าจริง)

ทางแก้เดิมคือบีบช่องวันให้แคบลงเพื่อเปิดทางให้ "พฤศจิกายน" ซึ่งย้ายปัญหาไปที่ช่องวันแทน

## Scope

- `src/lib/domain/tiers.ts` — แหล่งเดียวของลำดับมือ ชื่อรุ่น และตัวอย่าง
- ฟอร์มสร้างทัวร์นาเมนต์: ตัวเลือกเป็น `P · ตีประจำ` + ตัวอย่างของรุ่นที่เลือกใต้ช่อง
- หน้าจออื่นที่โชว์ตัวอักษรเปล่า ๆ เหมือนกัน — การ์ดหาทัวร์นาเมนต์ · หน้ารายการ ·
  หน้ารายละเอียด · หน้าสมัครสาธารณะ · หน้าโปรไฟล์
- `THAI_MONTHS_SHORT` ใน `src/lib/format.ts` + แถวสามช่องเท่ากัน + คืนระยะขอบส่วนเกิน

## Decisions

### ตัวอย่างอยู่นอกช่องเลือก ไม่ใช่ในข้อความของ option

ใส่ทั้งชื่อและตัวอย่างใน option เดียวได้ แต่ข้อความในช่องที่ปิดอยู่จะถูกตัดบนมือถือ
option จึงเหลือแค่ `P · ตีประจำ` แล้วตัวอย่างของรุ่นที่เลือกขึ้นเป็นบรรทัดใต้ช่อง
— แพตเทิร์นเดียวกับ "ตรงกับ วันอาทิตย์" ที่ `ThaiDateField` ใช้อยู่แล้ว

### ชื่อเดือนย่อไม่ใช่เรื่องสไตล์ แต่เป็นงบความกว้างที่มีจริง

เก็บไว้ใน `format.ts` แทนที่จะอยู่ในคอมโพเนนต์ เพื่อให้เทสอ่านได้โดยไม่ต้องโหลด
client component

### ตัวอักษรเดิมยังอยู่ในป้าย

`tierLabel('P')` คืน `'P · ตีประจำ'` ไม่ใช่ `'ตีประจำ'` เฉย ๆ เพราะคนในวงการ
สื่อสารกันด้วยตัวอักษรอยู่แล้ว และประกาศรับสมัครข้างนอกก็เขียนแบบนั้น

## Done Notes — 19 ก.ย. 2569 · เดิน flow จริงแล้วเจอสองบั๊ก

เกรพสั่งให้เดิน flow สร้างก๊วน → สร้างทัวร์นาเมนต์บน local ให้จบ ตั้งแต่บัญชีที่
**ยังไม่เป็นเจ้าของก๊วนไหนเลย** (มีน) ทั้งสองบั๊กข้างล่างเจอเพราะกดจริง ไม่มีเทสไหน
ในชุดเดิมจับได้ และทั้งคู่ "เงียบ" คือหน้าจอยังขึ้นปกติ แค่ผิด

### บั๊ก 1 — หน้ารายการทัวร์นาเมนต์ว่างเปล่าตลอด (`/app/tournaments`)

```
PGRST201: Could not embed because more than one relationship was found
          for 'tournaments' and 'groups'
hint: 'groups!tournaments_host_group_id_fkey' หรือ 'groups!tournament_teams'
```

`tournaments` ต่อกับ `groups` ได้สองทาง — `host_group_id` ตรง ๆ และผ่าน
`tournament_teams` แบบ many-to-many การ embed ว่า `groups (name)` เฉย ๆ จึงพัง

ที่ไม่มีใครเห็นเพราะ `const { data: rows } = await ...` **ทิ้ง error** แล้ว
`rows ?? []` เรนเดอร์เป็น "ยังไม่มีทัวร์นาเมนต์" — หน้าที่ query พังกับหน้าที่ว่างจริง
หน้าตาเหมือนกันเป๊ะ ตระกูลเดียวกับที่ซ่อน LSN-0043 ไว้นาน

**แก้:** ระบุ FK เป็น `groups!tournaments_host_group_id_fkey (name)` และ
`console.error` เมื่อ query ล้ม

### บั๊ก 2 — ปุ่ม "1 สัปดาห์ก่อนแข่ง" กรอกให้แปดวัน

`daysBefore()` สร้าง `Date` ที่เที่ยงคืนเวลาไทยแล้วเรียก `toISOString()` ซึ่งแปลงเป็น
UTC ก่อน เที่ยงคืนเวลาไทยคือ 17:00 ของ **วันก่อนหน้า** ใน UTC ตัดสิบตัวแรกจึงได้
วันที่เคลื่อนไปหนึ่งวัน

กดบนวันแข่ง 5 ธ.ค. 2570 ได้กำหนดปิดรับ **27 พ.ย.** ทั้งที่ควรเป็น 28 พ.ย.

**แก้:** ย้ายเป็น `dateMinusDays()` ใน `src/lib/format.ts` ที่ประกอบสตริงจาก
`getFullYear/getMonth/getDate` ตรง ๆ ไม่แตะ UTC
