# LSN-0013 — Organizer dashboard

**Type:** Feature · **Phase:** 5 · **Status:** Done

## Acceptance criteria
- [x] Session management dashboard with live status chip and progress.
- [x] Participant list with per-player payment state.
- [x] Payment summary: collected, pending, refunded, required.
- [x] Booking activity timeline rendered from `audit_logs`.
- [x] Fallback venue reordering and cancellation/refund controls.

## Review notes
- The dashboard showed `courts.base_price_thb` (an hourly rate) as "court cost"
  while the orchestrator gated on the real windowed price including peak and
  weekend rules — 300 vs 750 for the same session. Both the organizer dashboard
  and the public session page now call `court_price_for` so the number a user
  sees is the number the booking is gated on.
- PostgREST could not embed `sessions` from `bookings` (two foreign keys exist
  between them), so several venue and admin queries errored and rendered empty
  states. All now use the explicit `sessions!bookings_session_id_fkey` hint.
