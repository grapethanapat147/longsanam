# 🟢 LSN-0037 — ตัวอักษรบนปุ่มเขียวเป็นสีขาว

**Type:** Feature · **Phase:** 10 · **Status:** Done
**Source:** เกรพขอโดยตรง 18 ก.ย. 2569

## Goal

ปุ่มหลักและชิปสีเขียวใช้ **ตัวอักษรสีขาว** แทนตัวอักษรสีเข้ม โดยไม่ทำให้อ่านยากลง

## Context

`globals.css` ตั้ง `--color-on-brand: #0d1f18` ไว้พร้อมคอมเมนต์ว่า
*"White fails there; ink does not"* ซึ่งถูกต้อง — ผมคำนวณซ้ำแล้วได้ตรงกัน

| คู่สี | อัตราส่วน | AA (4.5:1) |
| --- | --- | --- |
| `on-brand #0d1f18` บน `brand-500 #12a563` | 5.37:1 | ผ่าน |
| `#ffffff` บน `brand-500` | **3.19:1** | **ไม่ผ่าน** |
| `#ffffff` บน `brand-600 #0a7a4f` | **5.37:1** | ผ่าน |
| `#ffffff` บน `brand-700 #076140` | 7.52:1 | ผ่าน |

**ทางออกคือขยับพื้น ไม่ใช่ยอมลดความคมชัด** — ขาวบนเขียว 600 ได้ค่าเท่าเดิมเป๊ะ
และ `docs/build_sen_sanam.py:34` มี assert ว่า *"ป้ายขาวบนเขียว 600 ต้องผ่าน AA"*
เขียนรออยู่ตั้งแต่แรก แปลว่าคู่นี้อยู่ในระบบสีตั้งแต่ต้นแล้ว

## Scope

- `--color-on-brand` → `#ffffff`
- ทุกที่ที่จับคู่ `bg-brand-500` กับ `text-on-brand` → `bg-brand-600` (5 จุด)
- สถานะ hover/active ของปุ่มหลักต้องเข้มลง ไม่ใช่สว่างขึ้น
  เดิม `hover:bg-brand-400` ซึ่งขาวบน 400 จะยิ่งแย่กว่า 500

## Non-goals

- ไม่เปลี่ยนสีเขียวของแบรนด์ ไม่เพิ่ม token ใหม่ — ใช้ขั้นที่มีอยู่แล้ว
- ไม่แตะตัวอักษรเขียวบนพื้นขาว (ยังเป็น `brand-600` ตามเดิม)
- ไม่แตะสี lime ซึ่งเป็นสีเส้น ห้ามใช้เป็นตัวอักษรอยู่แล้ว

## Acceptance Criteria

- [x] ปุ่มหลัก ชิปแบรนด์ และแท็บที่ถูกเลือก ใช้ตัวอักษรสีขาว
- [x] ทุกคู่สีที่เกิดขึ้นจริงผ่าน AA 4.5:1 — คำนวณ ไม่ใช่กะ
- [x] hover และ active ก็ผ่าน AA ด้วย ไม่ใช่ผ่านแค่สถานะปกติ
- [x] ไม่มีที่ไหนเหลือ `bg-brand-500` คู่กับ `text-on-brand`
- [x] เทสเดิมเขียวทั้งหมด

## Validation

- `npm run lint` · `npx tsc --noEmit` · `npm test` · `npm run build` ผ่าน
- คำนวณอัตราส่วนของทุกสถานะปุ่ม (ปกติ · hover · active)
- ตรวจเบราว์เซอร์ 375×812 ว่าปุ่มอ่านออกจริง
