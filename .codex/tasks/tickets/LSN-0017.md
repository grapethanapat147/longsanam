# LSN-0017 — Image uploads (Supabase Storage)

**Type:** Feature · **Phase:** 7 · **Status:** Backlog

## Goal
Venues and players can have a picture. `venues.cover_image_url` and
`profiles.avatar_url` already exist but nothing writes to them.

## Acceptance criteria
- [ ] `venue-images` and `avatars` buckets, public read, created by migration.
- [ ] Storage RLS: a user writes only into their own avatar folder; a venue
      member writes only into their venue's folder.
- [ ] Server actions validate MIME type and size before upload.
- [ ] Venue admin can upload/replace a cover image.
- [ ] Player can upload/replace an avatar.
- [ ] Images render on the venue portal, the discover cards and the session page.
- [ ] Replacing an image removes the previous object rather than orphaning it.
