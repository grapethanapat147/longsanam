# LSN-0012 — Cancellation, waitlist promotion and refunds

**Type:** Feature · **Phase:** 5 · **Status:** Done

## Acceptance criteria
- [x] Player cancels before the deadline -> slot released, refund computed by policy.
- [x] First eligible waitlist entry promoted with a configurable payment window.
- [x] Expired promotion cascades to the next entry.
- [x] Session cancellation refunds every paid participant.
- [x] Refund records carry status and provider reference.

## Review notes
- **The UI claimed a refund had happened when the provider had failed.** The
  action now returns the real outcome (`completed` / `pending` / `failed` /
  `none`) and the panel reports each distinctly. The slot is released either
  way; only the money statement changed.
- Verified: cancelling 72h before start returned the full 220 THB, the payment
  moved to `refunded`, and waitlist position 1 was promoted with a payment
  window while positions 2 and 3 kept waiting.
