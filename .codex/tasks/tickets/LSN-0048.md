# 🔴 LSN-0048 — ช่องเลือกผู้เล่นฝั่งตรงข้ามเสนอคนที่เลือกไม่ได้

**Type:** Bugfix · **Phase:** 11 · **Status:** Done
**Source:** เจอตอนเดิน flow บันทึกผลใน LSN-0045

## อาการ

ก๊วนที่รู้จักกันมักมีสมาชิกซ้ำกัน seed เองก็มี มีน อยู่ทั้ง แบดเช้าพระราม 9 และ
ก๊วนแบดบางนาตอนเย็น ฟอร์มบันทึกผลจึงโชว์ชื่อเดียวกันให้เลือกได้ทั้งสองฝั่ง

กดส่งแล้วฐานข้อมูลปฏิเสธด้วย constraint `matches_no_player_on_both_sides` (LSN-0030)
ผู้ใช้เห็นแค่ "เกิดข้อผิดพลาดที่ไม่คาดคิด" ที่ไม่ได้บอกว่าต้องแก้อะไร

## Scope

- `src/lib/domain/opponent-choice.ts` — ตัดคนที่อยู่ฝั่งตัวเองออกจากตัวเลือกฝั่งตรงข้าม
- `RecordMatchForm` ใช้ค่าที่ฟังก์ชันคืนมาทั้งรายการตัวเลือกและตัวที่เลือกอยู่
- ข้อความเมื่อไม่เหลือคู่แข่งให้เลือก

## Decisions

### ตัดตั้งแต่ตัวเลือก ไม่ใช่เตือนตอนกดส่ง

คนที่เลือกไม่ได้อยู่แล้วไม่ควรโผล่มาให้เลือก การปล่อยให้เลือกแล้วค่อยบอกว่าผิด
คือการให้ผู้ใช้เดาว่าอะไรผิดจากข้อความที่ไม่ได้บอก

### คิดตอนเรนเดอร์ ไม่ใช่ใน `useEffect`

ถ้าไปแก้ state ฝั่งตรงข้ามใน effect หลัง `a` เปลี่ยน จะมีจังหวะหนึ่งเฟรมที่ช่อง
ยังค้างอยู่ที่คนเดียวกับฝั่งตัวเอง ซึ่งเป็นจังหวะที่กดส่งได้พอดี — ฟังก์ชันจึงคืน
`selected` กลับมาด้วย แล้วหน้าจอใช้ค่านั้นตรง ๆ ทั้งตอนแสดงและตอนส่ง

### ด่านที่ตารางยังอยู่เหมือนเดิม

constraint ระดับตารางคือด่านจริง ตั๋วนี้แก้แค่ให้หน้าจอไม่เสนอทางที่ตันอยู่แล้ว
