# 🟢 LSN-0042 — ฟอร์มสร้างนัดเลือกวันเป็น พ.ศ.

**Type:** Feature · **Phase:** 10 · **Status:** Done
**Source:** เกรพขอโดยตรง 18 ก.ย. 2569
**Depends on:** LSN-0041 (`ThaiDateField`) — merge แล้ว

## Goal

ให้ช่องเลือกวันในฟอร์มสร้างนัดแสดงปีเป็น **พ.ศ.** เหมือนฟอร์มสร้างทัวร์นาเมนต์

## Context

LSN-0041 ทำ `ThaiDateField` ไว้แล้วและใช้กับฟอร์มสร้างทัวร์นาเมนต์
เหลือฟอร์มสร้างนัดที่ยังเป็น `<input type="date">` อยู่สองช่อง — **วันที่เล่น**
และ **วันปิดรับชำระ**

### ต่างจากฟอร์มทัวร์นาเมนต์ตรงไหน

ฟอร์มนี้ **ไม่ได้คุมค่าด้วย state** — ใช้ `name=` กับ `defaultValue` แล้วส่งผ่าน
`useActionState` ตามกลไกฟอร์มของเบราว์เซอร์ ส่วน `ThaiDateField` เป็น controlled

จึงต้องให้ `ThaiDateField` รับ `name` ได้ แล้วมันเรนเดอร์ `<input type="hidden">`
ให้เอง เพื่อที่ค่าจะยังไหลเข้าฟอร์มทางเดิม **ไม่ต้องรื้อวิธีส่งฟอร์มทั้งวิซาร์ด**
ซึ่งเป็นเส้นทางหลักของโปรดักต์ที่ห้ามพัง

## Scope

- เพิ่ม `name` ให้ `ThaiDateField` (ไม่บังคับ) → เรนเดอร์ hidden input ให้
- ใช้กับ **วันที่เล่น** และ **วันปิดรับชำระ** ในวิซาร์ดสร้างนัด
- คงค่าตั้งต้นเดิม (วันที่เล่น = อีก 7 วัน · ปิดรับชำระ = อีก 6 วัน)

## Non-goals

- ไม่แตะช่องเวลา (`type="time"`) ของฟอร์มนี้ — เกรพขอเรื่องปี พ.ศ.
  ถ้าจะเปลี่ยนเป็นตัวเลือกครึ่งชั่วโมงแบบฟอร์มทัวร์นาเมนต์ ควรเป็นตั๋วแยก
- ไม่เปลี่ยนวิธีส่งฟอร์มของวิซาร์ด
- ไม่แตะการตรวจค่าฝั่งเซิร์ฟเวอร์

## Acceptance Criteria

- [x] ทั้งสองช่องแสดงปีเป็น พ.ศ.
- [x] ค่าตั้งต้นยังเป็นอีก 7 วัน และอีก 6 วัน เหมือนเดิม
- [x] **ตั้งนัดได้จริงจนจบ และวันที่เข้าฐานข้อมูลถูกต้อง** — เส้นทางหลักต้องไม่พัง
- [x] ฟอร์มสร้างทัวร์นาเมนต์ยังทำงานเหมือนเดิม (ใช้ component ตัวเดียวกัน)
- [x] เทสเดิมเขียวทั้งหมด
